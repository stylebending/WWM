~~~~~~~~~~~~~~~~~~~~~~~~
The focus workaround uses undocumented Windows shell COM interfaces
(IApplicationView / IApplicationViewCollection). These are interface
definitions from Microsoft Windows; no Microsoft code is redistributed.
